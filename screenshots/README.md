# Screenshots Directory

This directory will contain screenshots of the extension in action.

## Required Screenshots

1. **logo.png** - The extension logo at 400x400px resolution
2. **notification.png** - Screenshot of the price comparison notification on a retail site
3. **popup.png** - Screenshot of the extension popup interface

## How to Add Screenshots

1. Take screenshots of the extension in action
2. Crop and resize as needed
3. Save in PNG format with the filenames mentioned above
4. Place in this directory

These screenshots are used in the README.md to showcase the extension functionality.
